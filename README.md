# SIAKAD STIKOM 2026

SIAKAD STIKOM 2026 merupakan aplikasi Sistem Informasi Akademik berbasis web yang dikembangkan menggunakan Next.js dan Tailwind CSS.

## Teknologi

- Next.js
- React
- Tailwind CSS
- JavaScript

## Instalasi dan Menjalankan Project

Clone repository:

```bash
git clone https://github.com/nusep/design-system-stikom.git
```

Masuk ke folder project:

```bash
cd siakad-stikom-2026cd
```

Install dependencies:

```bash
npm install
```

Jalankan aplikasi:

```bash
npm run dev
```

Buka http://localhost:3000 di browser.
